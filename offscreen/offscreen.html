Start screen capture

This capture window records video for GN Tracing (Firefox has no silent tab capture like Chrome). Firefox cannot open the share picker from the extension popup, so the next step happens here. It shares a window or a whole screen — not a single tab. In the browser picker, select the Firefox window that holds the recording target below (match the title). Prefer a window over a whole screen — sharing an entire screen also records everything else on it. After you share, this window minimizes; keep it running until you stop the recording.

Optional: site access for console and network evidence after navigation. This is separate from screen sharing. Without it the video still records, but console and network may stay empty once the page navigates. If you already allowed site access when starting, this step stays hidden.
