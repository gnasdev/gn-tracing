GN Tracing

GN Tracing is a browser extension that helps developers and QA create shareable bug reports. When you start a recording, GN Tracing captures the selected tab’s video, console logs, network activity, and related debugging artifacts, then packages them for review.

Purpose of GN Tracing

The purpose of GN Tracing is to record a user-selected browser tab on demand, build a replayable debugging package, store that package in the user’s own Google Drive (after the user connects Drive), and open a hosted replay so teammates can inspect what happened without reproducing the bug locally.

GN Tracing does not run continuous background surveillance. Recording starts only when you click record in the extension popup and stops when you stop recording or close the tab.

View GN Tracing on GitHub

What GN Tracing does

  • Records tab video and optional tab audio
  • Captures console, network, and WebSocket debugging data
  • Applies client-side redaction based on your privacy settings
  • Uploads a zip package to your Google Drive
  • Generates a shareable replay link for the hosted player

How to use GN Tracing

  1. Install the GN Tracing browser extension.
  2. Connect Google Drive in the extension popup (OAuth with limited Drive file access).
  3. Start recording the tab you want to debug, then stop when finished.
  4. Upload the package to Drive and open the generated replay URL.

Google Drive access

  • GN Tracing requests the Google Drive drive.file scope only.
  • It creates and opens files that GN Tracing itself creates or you open with it.
  • It does not request full access to every file in your Drive.
  • Replay files are link-readable so shared URLs work; you control deletion in Drive.
