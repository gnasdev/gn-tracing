# Chrome Web Store Assets

Generated by `npm run store:assets`.

The screenshots in this folder are composed from real captures of the extension popup, upload history page, and player pages. The temporary HTML fixtures load the repository's actual page markup and CSS, then populate representative state before Chrome headless captures each page.

Listing copy should describe **cloud storage** upload (Google Drive or Dropbox) and link-readable replay packages — not Google Drive only — when the Store build ships multi-provider support. Align store privacy questionnaire answers with `docs/compliance/privacy-policy.md` and `docs/compliance/chrome-web-store-submission.md`.
