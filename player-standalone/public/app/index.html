GN Tracing

Browser debugging extension and session replay

Purpose of GN Tracing

The purpose of GN Tracing is to help developers and QA create shareable debugging reports from a real browser session.

GN Tracing records a user-selected browser tab on demand, captures tab video and debugging artifacts (such as console logs, network activity, and related session data), packages that evidence for review, uploads the package to the user’s own Google Drive after the user connects Drive, and opens a shareable hosted replay so teammates can inspect what happened without reproducing the bug locally.

GN Tracing does not run continuous background surveillance. Recording starts only when the user clicks record in the extension popup and stops when the user stops recording or closes the recorded tab.

What GN Tracing does

  • Records tab video and optional tab audio from a tab the user chooses
  • Captures console logs, network requests, and WebSocket activity for debugging
  • Applies client-side redaction based on the user’s privacy settings
  • Uploads a recording package to the user’s Google Drive
  • Generates a shareable replay link on this website

How to use GN Tracing

  1. Install the GN Tracing browser extension.
  2. Connect Google Drive in the extension popup (limited Drive file access).
  3. Start recording the tab you want to debug, then stop when finished.
  4. Upload the package to Drive and open the generated replay URL.

How GN Tracing uses Google Drive

GN Tracing requests the Google Drive drive.file scope only. It creates and accesses files that GN Tracing creates or that the user opens with the app. It does not request full access to every file in the user’s Google Drive.

Uploaded replay packages are stored in the user’s Drive and may be made readable by link so shared replay URLs work. Users control deletion of those files in Google Drive.

This website

This page is the public application homepage for GN Tracing. The session replay player is hosted at https://tracing.gnas.dev/ and opens when someone uses a recording link generated by the extension.
