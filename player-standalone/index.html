Replay a recorded browser session with synced video, console logs, network traffic, and WebSocket activity.

View on GitHub

How to use

  1. Install the GN Tracing extension and start recording a tab.
  2. Upload the capture to Google Drive from the extension popup.
  3. Open the generated replay link to load the player with recording params.

Expected params

  • videos and metadata are required.
  • console, network, and websocket are optional.
  • Links are generated automatically after a successful upload.

Contributions are welcome if you want to help improve replay quality, debugging ergonomics, or sharing flow.
